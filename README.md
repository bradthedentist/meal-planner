# Meal Plan (Home Screen web app)

Static files, no build step. Serve this folder over HTTPS (GitHub Pages, Netlify, etc.).
On iPhone: open the URL in Safari → Share → Add to Home Screen.

Data: picks, servings, checkmarks and theme names are saved on the device in localStorage,
with an IndexedDB backup. Themes tab → Backup lets you copy/restore a plan to another device.
